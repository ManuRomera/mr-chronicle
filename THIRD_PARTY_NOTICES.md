# Avisos de terceros

MR · Chronicle no incluye código de terceros. La herramienta de postproducción llama a programas que instala cada usuario:

- **FFmpeg** — https://ffmpeg.org — LGPL 2.1+ / GPL según la compilación.
- **whisper.cpp** — https://github.com/ggml-org/whisper.cpp — MIT.
- **Modelos Whisper** de OpenAI — https://github.com/openai/whisper — MIT.
- **DeepFilterNet** — https://github.com/Rikorose/DeepFilterNet — MIT o Apache 2.0.

Revisa la licencia de cada modelo antes de cambiarlo.
